# Beauty Products Sales Analysis 💄

## Project Overview
This is a self-initiated data analysis project analyzing sales performance 
of 9 beauty products across 2025 and 2026. Built using Excel, SQL, and Power BI.

## Products Analyzed
Lipstick, Lip Balm, Lip Liner, Sunscreen, Cetaphil Moisturizer, 
Cetaphil Lotion, Sebamed Body Wash, Sebamed Lotion, Shampoo

## Key Results
| Metric        | 2025     | 2026     | Growth  |
|---------------|----------|----------|---------|
| Total Sales   | $10,840  | $17,320  | +59.8%  |
| Net Revenue   | $2,150   | $3,840   | +78.6%  |
| Net Profit    | $350     | $2,800   | +700%   |
| Total Loss    | $1,800   | $1,040   | -42.2%  |

## Tools Used
- Microsoft Excel (Data Cleaning, Pivot Tables, KPI Tracking)

- Power BI (Interactive Dashboard, Visualizations)
